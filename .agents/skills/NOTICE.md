# Skill attribution

The local `architect` and `interrogate` skills adapt workflows from [pstack](https://github.com/cursor/plugins/tree/ccb5507cec1546dc88135c1139c811e6c59115ba/pstack).
The source revision is `ccb5507cec1546dc88135c1139c811e6c59115ba`.

Original work: Copyright (c) 2026 Lauren Tan.
The original MIT license is in [LICENSE.pstack](LICENSE.pstack).

These adaptations use repository terminology and Buck2 checks.
They remove Cursor-specific tools, fixed model choices, and mandatory delegation.
They do not install the full pstack plugin or its transitive skill dependencies.
